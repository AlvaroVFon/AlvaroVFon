## 🧱 Foundations first

I care about the fundamentals before the tools: design patterns, SOLID, testing and
software architecture. I'd rather understand how something works under the hood than
wire libraries together.

- **Tests are the spec.** Behavior gets a failing test before it gets an implementation.
- **Boundaries before frameworks.** A module should make sense without knowing which library is behind it.
- **Boring where it matters.** Explicit data flow, clear errors, observable systems.
